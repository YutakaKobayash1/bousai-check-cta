防災のまとめ 防災チェック導線 v1.3.6

【目的】
防災チェック固定ページへの4つの導線を、Cocoon本体を直接編集せずに追加します。

1. PC：右端の追尾CTA
2. SP：画面下部の固定CTA
3. TOP：防災チェック専用カード
4. 記事本文末：文脈CTA

【安全な初期状態】
初回インストール時は「プレビューモード」がONです。
一般ユーザーには表示されません。

【設定手順】
1. WordPress管理画面 → プラグイン → 新規追加 → プラグインのアップロード
2. ZIPをアップロードして有効化
3. 設定 → 防災チェック導線
4. 「リンク先の固定ページ」で防災チェックの固定ページを選択
5. 設定を保存
6. 管理者として、任意のページURL末尾に ?bousai_cta_preview=1 を付けて確認

例:
https://bousai-matome.com/?bousai_cta_preview=1

【固定CTA】
- PC（1180px以上）: 画面右端
- 1179px以下: 画面下部
- 初期設定は25%スクロール後に表示
- footerが見えたら自動で消える
- /disaster-info/ 以下では初期状態で非表示
- 防災チェック固定ページ自身でも非表示

【TOPカード】
TOPのショートコードブロックに以下を追加:
[bousai_check_top_card]

【記事末CTA】
方法A: 個別記事のショートコードブロック
[bousai_check_article_cta]

方法B: 設定画面で「通常投稿の本文末へ自動表示する」をON

自動表示時は、記事タイトル・カテゴリ・タグから
備蓄 / トイレ・衛生 / 停電・電源 / 住まい・耐震 / 避難
の5系統を判定して文言を出し分けます。
該当しない場合は汎用文言になります。

【記事末CTAを出したくないカテゴリ】
設定画面の「記事末CTAを出さないカテゴリslug」へ
カンマまたは改行区切りで入力してください。

【GA4イベント】
event: bousai_check_cta_click

location:
- pc_floating
- sp_fixed
- top_card
- article_bottom

gtagがある場合はgtagへ送信し、
gtagがなくdataLayerが存在する場合はdataLayerへpushします。

【公開】
見た目と動作を確認した後、
設定 → 防災チェック導線 → 「プレビューモード」のチェックを外して保存すると、
一般ユーザーにも表示されます。

【注意】
記事末CTAの自動表示は初期状態でOFFです。
サイト全体へ一気に出す前に、ショートコードで数記事テストする運用を推奨します。
